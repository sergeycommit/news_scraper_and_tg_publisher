# Article Selector Module - Интеллектуальный выбор статей с помощью LLM

## Обзор

Модуль `article_selector.py` добавляет интеллектуальный выбор наиболее интересной статьи из всех доступных источников с использованием LLM (Large Language Model).

## Как это работает

### Принцип работы:

1. **Сбор заголовков** - модуль собирает заголовки, описания и URL статей со всех настроенных источников (Ars Technica, The Robot Report, Techxplore, Wired, The Verge, ZDNet)

2. **Двойная фильтрация опубликованных** - статьи проверяются на факт публикации дважды:
   - На уровне каждого скрапера (первая линия защиты)
   - На уровне Article Selector перед отправкой в LLM (вторая линия защиты)

3. **Анализ через LLM** - только неопубликованные статьи отправляются в LLM (через OpenRouter API) для анализа

4. **Выбор лучшей** - LLM выбирает одну наиболее интересную и значимую статью на основе критериев:
   - Практическое применение для обычного программиста (например вышла новая LLM модель)
   - Техническая глубина и инновационность
   - Актуальность и новизна информации
   - Потенциальный интерес для технической аудитории

5. **Публикация** - только выбранная статья скрапится полностью и публикуется в Telegram

## Преимущества

✅ **Качество над количеством** - публикуется только самая интересная статья вместо первой попавшейся

✅ **Экономия ресурсов** - полный скрапинг происходит только для одной выбранной статьи

✅ **Интеллектуальный выбор** - LLM учитывает контекст и делает обоснованный выбор

✅ **Гибкость** - критерии выбора можно настроить через переменные окружения

✅ **Защита от дубликатов** - двойная проверка исключает отправку уже опубликованных статей в LLM

## Настройка

### 1. Переменные окружения

Добавьте в файл `.env` (или используйте `config.env.example` как основу):

```bash
# OpenRouter API Configuration (обязательно)
OPENROUTER_API_KEY=your_openrouter_api_key_here
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1

# AI Model для селектора (рекомендуется)
AI_MODEL=google/gemini-pro

# Промпт для LLM-селектора (опционально - есть дефолтный)
ARTICLE_SELECTION_PROMPT=Ты - эксперт по техническим новостям в области ИИ, робототехники и технологий.

Твоя задача: из предоставленного списка статей выбрать ОДНУ наиболее интересную и значимую для технической аудитории.

Критерии выбора (по приоритету):
1. Техническая глубина и инновационность
2. Практическая значимость для индустрии
3. Актуальность и новизна информации
4. Потенциальный интерес для технической аудитории

Формат ответа: верни ТОЛЬКО номер статьи (число от 1 до N), без дополнительного текста.
```

### 2. Запуск

#### С LLM-селектором (рекомендуется):
```bash
python main.py
```

#### Старый метод (без LLM):

## API модуля ArticleSelector

### Класс ArticleSelector

```python
class ArticleSelector:
    def __init__(self):
        """Инициализация с загрузкой конфигурации из .env"""
        
    async def collect_all_articles(self, scrapers_list: List) -> List[Dict]:
        """
        Собирает заголовки статей со всех скраперов
        
        Args:
            scrapers_list: Список инициализированных скраперов
            
        Returns:
            Список словарей с информацией о статьях
        """
        
    async def select_best_article_with_llm(self, articles: List[Dict]) -> Optional[Dict]:
        """
        Использует LLM для выбора наиболее интересной статьи
        
        Args:
            articles: Список статей для выбора
            
        Returns:
            Выбранная статья или None
        """
        
    async def get_best_article(self, scrapers_list: List) -> Optional[Dict]:
        """
        Основной метод: собирает статьи и выбирает лучшую через LLM
        
        Args:
            scrapers_list: Список инициализированных скраперов
            
        Returns:
            Выбранная статья с дополнительной информацией о скрапере
        """
```

### Формат возвращаемой статьи

```python
{
    'title': str,         # Заголовок статьи
    'url': str,          # URL статьи
    'description': str,  # Краткое описание
    'date': date,        # Дата публикации
    'topic': str,        # Тема (AI, Robotics, Tech, etc.)
    'source': str,       # Название источника (ArsTechnicaScraper, etc.)
    'scraper': object    # Объект скрапера для дальнейшей работы
}
```

## Примеры использования

### Базовое использование

```python
from article_selector import ArticleSelector
from arstechnica_scraper import ArsTechnicaScraper
from techxplore_scraper import TechxploreScraper

async def main():
    # Инициализируем скраперы
    scrapers = [
        ArsTechnicaScraper(),
        TechxploreScraper(),
    ]
    
    # Инициализируем селектор
    selector = ArticleSelector()
    
    # Получаем лучшую статью
    best_article = await selector.get_best_article(scrapers)
    
    if best_article:
        print(f"Selected: {best_article['title']}")
        print(f"From: {best_article['source']}")
    else:
        print("No suitable article found")
```

### Кастомизация промпта

Создайте свой промпт в `.env`:

```bash
ARTICLE_SELECTION_PROMPT=Выбери самую технически сложную статью о машинном обучении.
Верни только номер статьи.
```

## Устранение неполадок

### LLM не выбирает статью

**Причина**: Недостаточно статей или проблемы с API

**Решение**:
1. Проверьте наличие `OPENROUTER_API_KEY` в `.env`
2. Проверьте баланс на OpenRouter
3. Проверьте логи в `article_selector.log`

### Ошибка "No articles collected"

**Причина**: Все статьи уже опубликованы или источники недоступны

**Решение**:
1. Проверьте логи каждого скрапера
2. Проверьте `published_urls.json` - возможно нужно очистить старые URL
3. Увеличьте `SCRAPING_DAYS` в `.env`

### Fallback на первую статью

**Причина**: LLM не смог выбрать или вернул некорректный ответ

**Решение**: 
- Модуль автоматически выберет первую статью из списка
- Проверьте логи для деталей
