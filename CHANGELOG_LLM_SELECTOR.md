# Changelog: LLM Article Selector

## Версия 2.0.0 - LLM-селектор статей

**Дата**: 2025-10-16

### 🎯 Основные изменения

Добавлен интеллектуальный модуль выбора статей через LLM, который анализирует все доступные статьи и выбирает наиболее интересную для публикации.

### ✨ Новые файлы

1. **`article_selector.py`** - Основной модуль LLM-селектора
   - Класс `ArticleSelector` для сбора и анализа статей
   - Интеграция с OpenRouter API
   - Интеллектуальный выбор лучшей статьи

2. **`ARTICLE_SELECTOR_README.md`** - Подробная документация модуля

3. **`LLM_SELECTOR_QUICK_START.md`** - Быстрый старт на русском языке

4. **`CHANGELOG_LLM_SELECTOR.md`** - Этот файл

### 🛡️ Защита от дубликатов

**Двойная проверка опубликованных статей:**
1. ✅ На уровне каждого скрапера в методе `get_article_headlines()`

### 🚀 Новый workflow

#### Было (v1.x):
```
Источник 1 → Первая статья → Публикация → СТОП
↓ (если нет)
Источник 2 → Первая статья → Публикация → СТОП
↓ (если нет)
...
```

#### Стало (v2.0):
```
Все источники → Сбор заголовков
              ↓
         LLM анализ
              ↓
    Выбор лучшей статьи
              ↓
  Полный скрапинг только её
              ↓
         Публикация
```

### 📊 Преимущества

1. **Качество**: Публикуется самая интересная статья, а не первая попавшаяся
2. **Экономия ресурсов**: Полный скрапинг только одной выбранной статьи
3. **Гибкость**: Критерии выбора настраиваются через переменные окружения
4. **Обратная совместимость**: Старый метод остался доступен

### ⚙️ Технические детали

#### Формат статьи для LLM:
```
Список статей для анализа:

1. [ИсточникA] Заголовок статьи 1
   URL: https://...
   Описание: ...
   Дата: 2025-10-16

2. [ИсточникB] Заголовок статьи 2
   ...
```

#### Формат ответа LLM:
- Только номер выбранной статьи (например: "3")
- Fallback: если LLM не может выбрать, берётся первая статья
