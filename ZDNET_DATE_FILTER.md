# ZDNet Scraper - Фильтрация по дате

## 📅 Настройки фильтрации

ZDNet скраппер автоматически фильтрует статьи по дате, показывая только статьи **не старше 2 дней** от текущей даты.

### Текущие настройки

```python
# В файле zdnet_scraper.py, строки 57-58
self.today = date.today()
self.yesterday = self.today - timedelta(days=2)
```

### Как это работает

1. **Расчет дат:**
   - `today` = текущая дата
   - `yesterday` = текущая дата - 2 дня

2. **Фильтрация статей:**
   - Статьи с датой >= `yesterday` проходят фильтр
   - Статьи с датой < `yesterday` отфильтровываются

3. **Логирование:**
   - Все отфильтрованные статьи записываются в лог
   - Показывается дата статьи и граница фильтрации

### Пример работы

Если сегодня 6 августа 2025:
- **Показываются статьи:** 4, 5, 6 августа
- **Отфильтровываются:** 3 августа и старше

### Изменение настроек

Чтобы изменить период фильтрации, отредактируйте строку 57 в `zdnet_scraper.py`:

```python
# Для статей не старше 1 дня
self.yesterday = self.today - timedelta(days=1)

# Для статей не старше 3 дней
self.yesterday = self.today - timedelta(days=3)

# Для статей не старше недели
self.yesterday = self.today - timedelta(days=7)
```

### Логи фильтрации

В логах `zdnet_scraper.log` вы увидите:
```
INFO - Date filter: articles not older than 2025-08-04 (2 days from today)
INFO - Article excluded (no date found): Article title...
INFO - Article filtered out (too old): Article title... (date: 2025-08-03, cutoff: 2025-08-04)
INFO - Found recent article: Article title... -> URL (date: 2025-08-05)
```

**Типы фильтрации:**
- **Исключены (no date found)** - статьи без даты не публикуются
- **Отфильтрованы (too old)** - старые статьи исключаются
- **Найдены (recent article)** - свежие статьи для публикации

### Проверка настроек

Для проверки работы фильтрации можно запустить:
```bash
python3 -c "
from zdnet_scraper import ZDNetScraper
from datetime import date, timedelta

scraper = ZDNetScraper()
print(f'Сегодня: {scraper.today}')
print(f'Фильтр: {scraper.yesterday}')
print(f'Диапазон: {scraper.yesterday} - {scraper.today}')
"
```

## 🎯 Преимущества фильтрации

- **Актуальность:** Только свежие статьи
- **Качество:** Исключение устаревшего контента
- **Эффективность:** Меньше обработки старых статей
- **Релевантность:** Соответствие ожиданиям аудитории

## 🔧 Решенные проблемы

### Проблема: Публикация старых статей
**Причина:** Скраппер использовал сегодняшнюю дату как fallback при отсутствии даты
**Решение:** Статьи без даты теперь исключаются из публикации

### Проблема: Неправильное извлечение дат из URL
**Причина:** Недостаточные паттерны для поиска дат в URL ZDNet
**Решение:** Добавлены дополнительные паттерны и улучшена валидация дат

### Проблема: Неточное логирование
**Причина:** Не было видно, почему статьи исключаются
**Решение:** Добавлено подробное логирование с указанием причин исключения
