# Исправление: Валидация HTML для Telegram

## ❌ Проблема

При публикации в Telegram возникала ошибка:
```
Can't parse entities: unclosed start tag at byte offset 1598
```

Это означало, что в HTML-разметке сообщения были:
- Незакрытые теги (например, `<b>` без `</b>`)
- Закрывающие теги без открывающих
- Неподдерживаемые HTML-теги
- Неэкранированные специальные символы (`<`, `>`, `&`)

## ✅ Решение

Добавлена функция `validate_and_fix_html()` в `telegram_publisher.py`, которая:

### 1. Удаляет неподдерживаемые теги

Telegram поддерживает только: `<b>`, `<i>`, `<u>`, `<s>`, `<code>`, `<pre>`, `<a>`

Все остальные теги удаляются:
```python
allowed_tags = ['b', 'i', 'u', 's', 'code', 'pre', 'a']
```

### 2. Проверяет баланс тегов

Использует стек для отслеживания открытых/закрытых тегов:
- Открывающий тег → добавляется в стек
- Закрывающий тег → удаляется из стека
- Незакрытые теги → автоматически закрываются в конце

### 3. Удаляет некорректные закрывающие теги

Если найден закрывающий тег без соответствующего открывающего - он удаляется:
```python
if tag_stack and tag_stack[-1] == tag_name:
    # Правильно закрытый тег
    tag_stack.pop()
else:
    # Закрывающий тег без открывающего - удаляем
    logger.warning(f"Found closing tag without opening: {match.group(0)}, removing")
```

### 4. Экранирует специальные символы

Экранирует `<`, `>`, `&` в обычном тексте (не в тегах):
```python
escaped = re.sub(r'&(?!(amp|lt|gt|quot|apos);)', '&amp;', escaped)
escaped = escaped.replace('<', '&lt;').replace('>', '&gt;')
```

## 📚 Дополнительная информация

### Поддерживаемые Telegram HTML-теги:

- `<b>` или `<strong>` - жирный текст
- `<i>` или `<em>` - курсив
- `<u>` - подчеркнутый текст
- `<s>` или `<strike>` - зачеркнутый текст
- `<code>` - моноширинный текст
- `<pre>` - предформатированный текст
- `<a href="URL">` - ссылка
