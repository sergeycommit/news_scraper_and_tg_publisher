# Руководство по использованию SYSTEM_PROMPT

## 🎯 Что такое SYSTEM_PROMPT?

`SYSTEM_PROMPT` - это системное сообщение, которое определяет роль и поведение AI модели при создании постов. Оно устанавливает контекст и инструкции для модели.

## 📝 Как использовать

### 1. Добавьте в .env файл:

```env
SYSTEM_PROMPT=Ты - эксперт по созданию вирусных постов для Telegram. Твоя задача - создавать интересные, информативные и привлекательные посты на русском языке. Используй эмодзи, структурируй информацию, делай посты читаемыми и вирусными. Всегда включай заголовок в начале поста.
```

### 2. Логика работы:

- **Если `SYSTEM_PROMPT` задан**: Используется кастомный системный промпт
- **Если `SYSTEM_PROMPT` не задан**: Используется стандартный промпт
- **При рефакторинге поста**: Используется специальный промпт для сокращения

## 🔧 Примеры SYSTEM_PROMPT

## 🎨 Преимущества использования SYSTEM_PROMPT

### ✅ Контроль стиля:
- Определяет тон и стиль постов
- Устанавливает правила форматирования
- Контролирует использование эмодзи

### ✅ Консистентность:
- Все посты создаются в едином стиле
- Сохраняется брендинг канала
- Поддерживается качество контента

### ✅ Гибкость:
- Можно легко изменить стиль постов
- Адаптация под разные темы
- Настройка под целевую аудиторию

## 📊 Логирование

В логах вы увидите:
```

```

## 🔄 Приоритеты промптов

1. **Рефакторинг поста**: Специальный промпт для сокращения
2. **Кастомный SYSTEM_PROMPT**: Если задан в .env
3. **Стандартный промпт**: По умолчанию

## 💡 Советы по написанию SYSTEM_PROMPT

### ✅ Хорошие практики:
- Будьте конкретными и четкими
- Указывайте язык и стиль
- Определяйте структуру постов
- Устанавливайте ограничения по длине

### ❌ Избегайте:
- Слишком длинных промптов
- Противоречивых инструкций
- Неясных требований
- Избыточной информации
